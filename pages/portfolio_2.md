# 인스타그램 인플루언서 데이터 분석 프로젝트

## 📝 프로젝트 개요
**데이터 분석 첫번째 프로젝트**

## 🎯 메인 목표
인스타그램 인플루언서에 대한 광고 효율 데이터 분석을 통해 최적의 마케팅 전략 도출.

## 💻 개발 환경
- **언어**: Python
- **라이브러리**: Pandas
- **도구**: Google Colab

## 🔗 프로젝트 링크
- [GitHub Repository 바로가기](https://github.com/signectionlab/signectionlab.github.io.git)

---

### 📊 데이터 인사이트
수집된 인플루언서 데이터들을 Pandas를 통해 정리하고 정제하여, 비용 대비 가장 높은 전환율(Conversion Rate)과 참여율(Engagement)을 끌어낼 수 있는 인플루언서 그룹을 선별했습니다. 이를 통해 마케팅 예산을 가장 효율적으로 분배할 수 있는 인사이트를 도출했습니다.
